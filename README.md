# E-Commerce Revenue & Churn Analysis
This project analyzes customer behavior using RFM segmentation and predicts churn using Machine Learning.

## Key Sections
- RFM Segmentation (Champions, Loyal, At Risk, Lost)
- Revenue Concentration Analysis
- Geographical Churn Mapping
- Cohort Retention Analysis
